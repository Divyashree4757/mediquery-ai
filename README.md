 MediQuery AI

Natural Language Query System using AlloyDB (PostgreSQL)

## Features
- Natural language to SQL conversion
- Custom dataset
- PostgreSQL function-based querying

## Example
SELECT * FROM nl_query('show patients with fever');

## 🔥 Advanced Feature: Semantic Search (Neighbor Loop)

This project includes a semantic search system using AlloyDB AI.

- Uses vector embeddings
- Retrieves results based on meaning
- Works even without exact keyword match

### Example

Search: "furniture"

Result:
- Sofa
- Chair
- Table
